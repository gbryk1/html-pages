🧪 HTML tools z lokalnym modelem

Samodzielne narzędzia HTML w duchu „HTML tools” Simona Willisona: zero backendu, zero build-stepu, modele neuronowe wbudowane w strony jako base64 i uruchamiane w przeglądarce przez WebAssembly / WebGPU (transformers.js). Dane nie opuszczają urządzenia.

🎙️ Speech-to-Text

Whisper tiny (wielojęzyczny, q8) wbudowany w jeden plik HTML (58 MB). Nagrywaj z mikrofonu lub wgraj plik audio — transkrypcja liczona lokalnie.

💬 Chat

SmolLM2-135M-Instruct (q4f16, 117 MB) w plikach base64 obok strony. Prosty czat z modelem językowym działającym w Twojej przeglądarce.

👁️ Cassandra od środka

Animowany kurs architektury Apache Cassandra w stylu Head First: pierścień tokenów, gossip, ścieżki zapisu/odczytu, kompakcja, tombstones, drzewa Merkle. Bez modelu ML — czysty HTML/SVG.

🧑‍💼 Copilot dla PM-ów

Animowany przewodnik po Microsoft 365 Copilot i Outlook Copilot dla kierowników projektów: grounding przez Microsoft Graph, uprawnienia, RAID log, status z 7 dni i nietrywialne scenariusze krok po kroku.

⌨️ Claude Code od zera do eksperta

Animowany przewodnik (EN) po Claude Code: pętla agenta, okno kontekstu, CLAUDE.md, tryby uprawnień, plan mode, skille, subagenci, hooki, MCP, pluginy, równoległe sesje, CI, modele i dobre praktyki.

📜 Kafka od środka: od zera do eksperta

Animowany przewodnik (EN) po wewnętrznej architekturze Apache Kafka 4.3: log i segmenty, replikacja i high watermark, KRaft, rebalanse KIP-848, idempotencja, transakcje, kompakcja, tiered storage, share groups, operacje, obsługa błędów i dobre praktyki Spring Kafka.

Dlaczego model czatu nie jest w jednym pliku? GitHub Pages nie pozwala na plik większy niż 100 MB, a 117 MB wag po zakodowaniu base64 daje ~156 MB. Jest więc podzielony na części i sklejany w pamięci. Narzędzie speech-to-text mieści się w jednym pliku.
